## 0. 先说清楚

| 项目 | 内容 |
|------|------|
| 日期 | **8/13 周四**（第三天） |
| 活动 | 租 **公路车（Road Bike）**，骑行环岛 / 大半圈 |
| 起点 | 卡塔坦尼 / 卡塔–卡隆一带 |
| 建议人数 | **有骑行基础的大人**（「租一辆」按 1 人写；若两人骑另订第二辆） |
| 孩子 | **不建议**跟公路车环岛；留酒店玩水 / Kids Club，另一位家长照看 |
| 季节 | 8 月雨季：热、湿、午后易雷阵雨；**尽量清晨出发、中午前完成大段** |

> 全岛闭环公路骑行体感通常 **约 100–150 km 量级**（视路线），丘陵多、车流不小，属于 **中高强度** 日，不是景区观光骑。  
> 若体力/天气不够，改骑本文 **「南线半日圈」** 或 **「西海岸往返」**，同样爽，更稳。

## 1. 三种路线（按强度选）

### 方案 A｜南线经典圈（推荐默认）⭐

适合：第一次在普吉骑公路车、还要兼顾亲子行程节奏。

| 项目 | 约略 |
|------|------|
| 参考路线 | 卡塔 → 卡隆观景/沿海 → 奈涵 / 拉威 → 神仙半岛（Promthep）方向 → 经南部山路回到卡塔 |
| 距离 | 大约 **50–80 km**（视绕法） |
| 用时 | **3.5–6 小时**（含拍照、补给） |
| 看点 | 观景点、南端海角、拉威一带；坡有但可控 |
| 优点 | 当天能回酒店陪家人晚饭；遇雨好缩短 |

**适合作为「环岛感」又不把自己骑废的选择。**

### 方案 B｜西海岸 + 北段（大半岛）

| 项目 | 约略 |
|------|------|
| 参考路线 | 卡塔 → 卡隆 → 巴东 → 卡马拉 / 苏林 → 视体力决定是否继续北上 → 原路或东侧绕回 |
| 距离 | 大约 **80–120 km** |
| 用时 | **6–9 小时** |
| 注意 | **巴东山路（Patong Hill）** 陡、车多；雨天更危险 |
| 适合 | 有爬坡经验、能在热天连续骑的人 |

### 方案 C｜全岛大环（仅限状态极好）

| 项目 | 约略 |
|------|------|
| 距离 | 常见说法约 **120–200 km 级**（取决于是否贴岸、是否绕北端机场一带） |
| 用时 | 极易变成 **一整天**；8 月午后雷雨风险高 |
| 建议 | 除非你日常能轻松骑百公里丘陵，否则 **8/13 不优先** |
| 备选 | 拆成「南线今天 + 北线下次」更理智 |

## 2. 当天时间表（建议按方案 A）

| 时间 | 安排 |
|------|------|
| 05:30–06:00 | 起床、简单吃东西、涂防晒、检查装备 |
| 06:00–06:30 | 取车 / 酒店取送车；调座高、试闸 |
| **06:30–10:30** | **主力骑行窗口**（最凉快、车流相对可控） |
| 10:30–12:00 | 补给、看天气；决定是否加段或掉头 |
| 12:00–14:00 | 尽量结束大骑或已在回程；躲午后暴雨 |
| 下午 | 还车 → 回卡塔坦尼冲凉 → 泳池陪孩子 |
| 晚上 | 全家酒店或卡塔主街晚餐 |

骑行的大人：前一晚早睡；当天酒店早餐可打包能量食物，或 7-Eleven 买香蕉、面包、电解水。

## 3. 哪里租公路车（卡塔/卡隆友好）

以下为常见渠道方向，**下单前以商家实时库存、尺码、送车报价为准**。

| 渠道类型 | 说明 | 动作 |
|----------|------|------|
| 卡隆/卡塔本地车行 | 如 Amazing Bike Tours 一带（卡隆 Patak Rd 附近有公路车出租信息） | 邮件/WhatsApp 问：Road bike 日租、尺码、是否含头盔、押金、能否送到 Katathani |
| 专业骑行店（普吉） | Siam Bike Tours、Phuket Cycling Thailand、GIANT 合作店等 | 官网订公路车；问清取还点、周日是否营业、送车到 Kata Noi 费用 |
| 酒店礼宾 | 前台/Tour Desk 代订 | 方便，但可能加价；要确认是 **公路车** 不是山地车/共享单车 |

### 预订时务必确认的清单

- [ ] 车型：**Road bike / 公路车**（不是 MTB、不是电助力除非你想要）
- [ ] **车架尺码**（按身高；错误尺码会骑废膝盖）
- [ ] 变速：至少 Shimano 105 级更舒服（爬坡用得上）
- [ ] **头盔**是否包含（必须有）
- [ ] 水壶架 / 是否自备水壶
- [ ] 日租时段：例如 09:00–19:00 还是 24 小时；**能否 6 点取车**（环岛关键）
- [ ] 押金金额与支付方式（常见较高，信用卡预授权或现金）
- [ ] 损坏/丢车责任、是否可加购车险
- [ ] **送车到 Katathani / 卡塔** 费用与时间
- [ ] 还车地点与最晚时间
- [ ] 紧急联系电话（爆胎、事故）

### 价格粗估（会变）

| 项目 | 参考 |
|------|------|
| 公路车日租 | 约 **800–1,500+ ฿/天**（碳架更高） |
| 送车（卡塔一带） | 可能 **几百至一千多泰铢/趟** |
| 押金 | 公路车可能较高（有店到数万泰铢级或等值外币/刷卡预授权） |

> 只租 **1 天（8/13）**；提前 **至少 3–7 天** 锁定尺码，旺季/周末更要早订。

## 4. 装备与携带

### 必带 / 必穿

- [ ] 骑行短裤或内垫、速干上衣
- [ ] 头盔（店家提供也要自己确认松紧）
- [ ] 骑行眼镜或墨镜、手套（可选但推荐）
- [ ] SPF50+ 防晒、汗巾
- [ ] 手机 + 支架或上管袋；**当天流量要好使**（导航）
- [ ] 充电宝、充电宝线
- [ ] 现金小额 + 一张卡（补给、应急 Grab）
- [ ] 护照复印件或酒店房卡复印件（店家常要证件；**尽量不留护照原件**，用复印件+押金卡）
- [ ] 雨衣薄款（8 月必备）
- [ ] 能量胶 / 香蕉 / 电解质饮料

### 导航

- 下载 **Komoot / Strava / Google Maps** 离线普吉地图
- 出发前把选定路线 GPX/链接存好
- 关键话：**左侧通行**；大路口减速；不听播客分神

## 5. 安全与雨季规则（必读）

1. **靠左行驶**；假设对面随时有人加塞、摩托钻车。  
2. **红旗海滩与骑行无关，但山路湿滑 = 减速**；雷雨时找屋檐，别硬骑下坡。  
3. 巴东、主路车流高峰尽量避开；早骑是最好的安全策略。  
4. 不边骑边看手机；停车再拍照。  
5. 爆胎：先靠边安全处；打车行电话；不行就 Grab 叫车（车放后备箱需沟通，或请店家拖车）。  
6. 买旅游保险，确认是否覆盖 **自行车运动**（有的免责条款要看清）。  
7. 酒精当日骑行前不沾。  
8. 与留在酒店的家人约好：**定位分享 + 每 1–2 小时报平安**。

## 6. 和家人怎么配合（亲子不冲突）

| 角色 | 8/13 安排 |
|------|-----------|
| 骑行的大人 | 清晨出发，争取中午前结束大段，下午回酒店 |
| 留店的大人 + 两个孩子 | 按主攻略：水上乐园 / 泳池 / Kids Club；中午避雨 |
| 汇合 | 约好下午还车后的碰面时间；晚饭一起 |
| 备选 | 若清晨下雨取消环岛 → 整天改回酒店度假，公路车改期或退订（订时选可取消） |

主攻略里 Day 3 原「酒店深度日」改为：**上午环岛骑行（大人）+ 酒店亲子（其余人）**。

## 7. 补给点思路（南线）

- 出发前酒店/7-Eleven 补满水  
- 卡隆、拉威、奈涵一带沿途便利店多，别等空罐再找  
- 热天：**少量多次喝**；出现头晕、抽筋立刻降强度、找阴凉  
- 午餐可简单解决，避免吃太撑再爬坡
