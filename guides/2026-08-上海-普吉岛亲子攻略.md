## 1. 证件与入境

### 1.1 签证

- 中国普通护照可免签入境泰国，单次停留不超过 **30 天**（本行程足够）。
- 护照有效期建议 **6 个月以上**，空白页充足。
- **4 人各自**准备护照原件。

### 1.2 必做：TDAC 电子入境卡

#### TDAC 是什么？

**TDAC = Thailand Digital Arrival Card（泰国数字化入境卡）**。

以前落地要填纸质入境卡（白卡）；现在改为**出发前在网上填写**的电子版。入境时移民官会核对，相当于你的「电子海关/入境申报」。

- **谁要填**：所有外国旅客（你们 4 人**每人一张**）。
- **在哪填**：泰国移民局官网（免费）https://tdac.immigration.go.th  
  ⚠️ 只认官网，不要用收费代办或不清楚来路的链接。
- **何时填**：官方要求在抵达泰国前 **不超过 3 天（含抵达当天）** 提交，也常说成约 **72 小时窗口**。  
  - **不能太早填**：超过 3 天系统通常不接受 / 无效。  
  - **不是“必须卡点满 72 小时才填”**：窗口内（提前 2–3 天到出发前）随时可填。  
  - **抵达当天补填也可以**，但不建议拖到落地再填（排队、没网会很麻烦；机场或有补填点但会耽误）。  
  - **举例**：8/11 抵达 → 大约从 **8/9** 起就可以填（以官网当天能否选中你的抵达日为准）。  
  - 以泰国时间（GMT+7）理解日期更稳。
- **要填什么（常见项）**：护照信息、航班号、抵达日期、在泰住址（填酒店英文名和地址）、联系方式等。
- **填完后**：保存确认页 / 二维码 / 邮件，通关时手机出示或打印备用。
- **不填会怎样**：可能被拦下补填、延误通关，严重时影响入境，所以当成必做项。

#### 操作清单

- [ ] 大人 A 已填
- [ ] 大人 B 已填
- [ ] 孩子（六年级）已填（可由父母代填，信息用孩子护照）
- [ ] 孩子（三年级）已填
- [ ] 确认页已截图进相册 / 云盘

> 酒店英文名填写示例（以订单为准）：`Katathani Phuket Beach Resort`，地址用订单或官网英文地址。

### 1.3 入境备查材料（建议打印或手机可快速出示）

- [ ] 往返机票行程单（去程 + **回程 9C8666**）
- [ ] 酒店预订单（英文姓名与护照一致）
- [ ] TDAC 确认信息（4 人）
- [ ] **财力**：现金 + 银行卡（详见下一节）

### 1.3.1 落地抽查财力：具体怎么应对

不是人人查，但是**抽查到了就得拿得出东西**。中国驻泰使馆明确提醒：免签≠无条件入境，缺材料可能被拒。

#### 官方口径（优先按这个准备）

据中国驻泰国大使馆提醒（通常个人 / 家庭）：

| 对象 | 建议备妥 |
|------|----------|
| 个人 | 不少于约 **10,000 泰铢**（或等值外币）现金 |
| **家庭（你们 2 大 2 小算一家）** | 不少于约 **20,000 泰铢**（或等值外币）现金 |
| 辅助 | 同时备妥 **银行卡、电子支付/余额记录** 等 |

> 另有部分旅游资讯会提到更高口径（如个人 2 万 / 家庭 4 万泰铢）。执法看现场官裁量。  
> **稳妥做法**：你们现金本来就计划带 **20,000–25,000 ฿**，已覆盖使馆「家庭 ≥2 万」；若想更宽裕，现金提到约 **30,000–40,000 ฿** 也行（反正度假用得掉），并带好可刷的国际卡。

**认什么**

- **最硬**：随身 **实物现金**（泰铢或人民币/美元等外币纸币均可，按约等值算）。  
- **辅助**：信用卡/储蓄卡、手机银行余额截图、支付宝余额等——使馆建议一并备着；是否被接受看当面官员，**别把希望全押在手机截图上**。  
- 机票、酒店订单也是「你有计划、会离开」的证明，和财力一起看。

#### 通关时怎么做（步骤）

1. **排队前**：把材料按顺序放好（护照夹或透明文件袋）  
   - 护照  
   - TDAC 确认页  
   - 回程机票 + 酒店订单（手机相册置顶或打印）  
   - 现金放大人贴身（别全部分散在托运行李里）  
   - 银行卡放钱包  
2. **到柜台**：递护照；问话用简单英语或中文（很多柜台能处理中国游客）。  
3. **若被问目的**：  
   - *Tourism / holiday*（旅游）  
   - 住：*Katathani Phuket Beach Resort, Kata Noi*  
   - 几天：*4 nights, leave on 15 August, flight 9C8666*  
4. **若被要求看钱 / show money**：  
   - 冷静掏出现金给他看一下（不必全部摊开在公共台面上招摇，够数即可）  
   - 可顺带出示银行卡：*credit card / bank card also*  
   - 不要争辩政策、不要掏手机玩很久找不到截图  
5. **若还要酒店/机票**：马上出示已准备好的订单。  
6. **盖章放行后**再收拾钱包，别在柜台磨蹭堵后面的人。

#### 话术备忘（够用就行）

| 对方可能问 | 你可答 |
|------------|--------|
| Purpose of visit? | Tourism. Family holiday. |
| How long / when leave? | 4 nights. Leave August 15. Flight 9C8666. |
| Where stay? | Katathani Hotel, Kata Noi Beach. |
| Show money / funds? | Yes.（出示现金）Here is cash. Also cards. |

#### 你们一家的推荐配置

| 项目 | 建议 |
|------|------|
| 现金 | 全家合计 **至少 20,000 ฿**；更稳 **25,000–40,000 ฿**（或等值人民币，约 5,000–8,000 元） |
| 谁拿 | **两位大人分持**，过关时由一位主要应答、出示 |
| 卡 | 至少 1–2 张已开通境外的 Visa/Mastercard |
| 材料包 | 起飞前装进一个文件袋：打印件 + 手机置顶相册 |
| 孩子 | 一般跟家庭一起过；财力按家庭合计理解，但材料 4 人护照和 TDAC 都要齐 |

#### 不必过度焦虑的点

- 多数旅游客快速放行，**不是人人掏钱包**。  
- 你们已订往返机票 + 五星级酒店，故事完整，抽查时配合出示即可。  
- 真正危险的是：什么都不带、说不清住哪、没有回程、只靠「我有支付宝」却拿不出任何现金。

#### 和「带多少度假现金」的关系

- 过关抽查：先满足 **家庭 ≥2 万泰铢量级** 的「拿得出」。  
- 度假花销：仍按攻略现金建议使用；多带的现金不是浪费。  
- 两套逻辑合一：**带够现金，过关能亮、岛上能花。**

### 2.5 手机上网（流量 / Wi‑Fi）

酒店度假为主，**酒店 Wi‑Fi + 大人手机有网** 就够；孩子平板连酒店 Wi‑Fi 即可。至少保证 **1–2 部手机** 落地就能上网（找接机、地图、应急）。

#### 方案对比（按推荐顺序）

| 方案 | 适合谁 | 优点 | 注意 |
|------|--------|------|------|
| **A. 旅游 eSIM**（出发前装好） | 手机支持 eSIM | 落地关飞行模式就有网，免机场排队 | **先确认支持 eSIM**；部分国行 iPhone 不支持 |
| **B. 机场 / 市区实体 SIM** | 不支持 eSIM | AIS / True 游客卡好办 | 机场可能排队；备护照 |
| **C. 国内运营商国际漫游日包** | 图省事 | 不用换卡，原号可收短信 | 通常更贵；出发前开通 |
| **D. 只靠酒店 Wi‑Fi** | 几乎不出门 | 零成本 | 机场/路上/沙滩没网；**不推荐当唯一方案** |

> 已订酒店接送，不等于可以完全没流量；延误通知、翻译、应急仍需要网。

#### 一家四口实用搭配

| 角色 | 建议 |
|------|------|
| 大人手机 ×1–2 | 开 **eSIM / 本地卡 / 漫游**（主力） |
| 另一部大人手机 | 可留国内卡收验证码；需要时开热点 |
| 孩子手机/平板 | 酒店 Wi‑Fi 即可，一般不必单独买卡 |
| 流量需求 | 5 天酒店为主：导航 + 微信/支付宝 + 偶尔视频 → 约 **1–2GB/天**；选 **5–8 天、约 10–20GB** 或短天数组套餐 |

普吉卡塔一带 **AIS、True** 通常都够用；套餐天数盖住 **8/11–8/15** 即可。

#### eSIM 要点

1. 出发前在有 Wi‑Fi 处购买并 **先安装**（Airalo / Nomad / KKday 等泰国套餐均可比价）。  
2. 双卡机：国内卡可留着收短信，**蜂窝数据切到 eSIM**。  
3. 落地后关闭飞行模式，打开 eSIM 数据。  
4. 自查是否支持：设置里有无「添加 eSIM / 添加蜂窝套餐」；没有则改走 B 或 C。

#### 实体 SIM（机场买）

- 柜台常见 **AIS / True** 游客套餐，护照办理，多数即插即用。  
- 旧卡收好，回国换回。  
- 不想排队：优先出发前 eSIM 或漫游。

#### 酒店 Wi‑Fi

- 卡塔坦尼客房有 Wi‑Fi，入住问前台密码。  
- 适合晚上聊天、孩子平板、看视频。  
- 泳池边/沙滩别当唯一依赖。

#### App 与通讯

| 用途 | 说明 |
|------|------|
| 微信 / 支付宝 | 泰国流量或酒店 Wi‑Fi 一般可用 |
| Grab / Maps / 翻译 | 装在有流量的手机上 |
| 银行验证码短信 | 保留国内号；或出发前减少依赖短信的操作 |
| 打回国内 | 优先微信语音；漫游电话较贵 |
| 联系酒店 | 邮件 + 尽量留 **WhatsApp**（国际酒店常用） |

#### 上网专项 Checklist

- [ ] 确定哪 1–2 部手机负责流量  
- [ ] eSIM：已买已装会切换 / 或已开通漫游 / 或准备买实体卡  
- [ ] 下载离线：Google Maps 普吉离线地图  
- [ ] 充电宝；避免双卡误走高额漫游（看清「蜂窝数据」选中哪张卡）  
- [ ] 公共 Wi‑Fi 少登网银；支付优先用官方 App

## 3. 住：卡塔坦尼用法

### 3.1 为什么适合你们

- 位置：小卡塔（Kata Noi），比大卡塔/巴东安静，适合亲子。
- **Aqua Jungle 水上乐园**：滑道、漂流河、戏水区（约 09:00–17:30；滑道常分场次）。
- 多个泳池 + 儿童池；救生衣可问前台/乐园。
- **Chang Noi Kids Club**（约 4–12 岁）：手工、小厨、电影等，两大孩子年龄都合适。
- 餐厅有儿童餐；可问加床/家庭房政策。

### 3.2 入住注意

- [ ] 确认房型：家庭房 / 连通房 / 加床（两人孩子分床更易睡）
- [ ] 抵达后问清：水上乐园位置与场次、Kids Club 是否需预约、儿童早餐是否收费
- [ ] 8/11 晚到：已告知酒店 ETA（预计 15:30–16:30）
- [ ] 8/15 早走：前一晚收拾；问清行李寄存；一般不依赖 late check-out
- [ ] 房间尽量海景（雨天也能在阳台看海）

### 3.3 雨季下海规则

- 8 月西海岸（卡塔/卡隆/巴东）常挂 **红旗**。
- **红旗 = 禁止下海**（包括「只到脚踝」），有离岸流风险。
- 游泳主场 = **酒店泳池 + 水上乐园**。

## 4. 衣：行李清单

### 4.1 天气预期

- 白天约 29–31℃，夜间约 25℃，湿度高。
- 雨多在 **午后短时暴雨**，很少下一整天。
- 策略：**上午户外/玩水，下午酒店或室内**。

### 4.2 每人必带

- [ ] 速干短袖 / 短裤 / 裙子 3–4 套（少带牛仔裤）
- [ ] 泳衣 2 套 + 罩衫
- [ ] 薄雨衣或折叠伞
- [ ] 防滑凉鞋 + 可走路的鞋
- [ ] 帽子、墨镜、**防晒霜**（见下节指数建议）
- [ ] 薄外套（机舱 + 进寺庙遮肩）
- [ ] 充电宝、转换插头（泰国双圆孔，220V）
- [ ] 防水手机袋

### 4.2.1 防晒霜怎么选（普吉 · 亲子）

雨季紫外线仍强，泳池/海边反射更伤。建议**大人、孩子分开带**（儿童用儿童配方）。

| 对象 | 防晒指数建议 | 其他要求 |
|------|--------------|----------|
| 大人 | **SPF 50 / SPF 50+**，**PA+++ 或 PA++++** | 选 **防水/防汗（Water resistant）**，适合游泳玩水 |
| 孩子（8–12 岁） | 同为 **SPF 50 / 50+**，**PA+++ 及以上** | 优先 **儿童专用**、温和少刺激；敏感肌可选物理/混合（氧化锌、二氧化钛） |
| 脸部 | 可与身体同款，或另备清爽面部防晒 | 易长痘可选油皮配方；忌用过期产品 |

**怎么理解这些字母**

- **SPF**：防紫外线 B（晒红、晒伤）。日常城市 SPF30 往往够，**热带度假玩水建议直接 SPF50/50+**。  
- **PA+/++/+++/++++**：防紫外线 A（晒黑、光老化）。去普吉尽量 **PA+++ 或 PA++++**。  
- **防水**：减少下水后失效，但仍需擦干后补涂，不是「涂一次管一天」。

**用量与补涂（比买多贵更重要）**

- 全身大约：**两指腹到三指腹**的量（很多人只涂到标称效果的一半）。  
- 出门前 **15–20 分钟**先涂。  
- **每 2 小时补一次**；出水、大汗、擦毛巾后马上补。  
- 阴天、阵雨间隙也要涂——云层挡不全 UVA。

**搭配（别只靠防晒霜）**

- 宽檐帽 / 鸭舌帽、墨镜  
- 上午玩水，**11:30–14:30** 尽量回酒店阴凉处  
- 可选：防晒袖套、儿童防晒泳衣（UPF 衣物很省事）  
- 晚上可用温和保湿/晒后修复乳，缓解紧绷

**购买小提示**

- 国内买熟品牌即可（碧柔、安热沙、妮维雅儿童、启初/宝宝用等），不必迷信当地买。  
- 飞机随身带：单瓶一般 ≤100ml；大瓶托运。  
- 酒店/便利店也能买到，但选择少、可能更贵——**主用的出发前带好**。  
- 孩子脸若容易进眼睛，选「儿童 / 无刺激」并避免往眼周堆太厚。

### 4.3 带娃加成

- [ ] 儿童防晒霜、驱蚊液（成人/儿童防晒见 §4.2.1，建议 SPF50+）
- [ ] 退烧药、止泻药、创可贴、常用感冒药
- [ ] 泳镜、儿童救生辅助（若孩子不熟水性可自备，酒店也可能有）
- [ ] 少量孩子爱吃的零食（飞机 + 第一天）
- [ ] 换洗衣物按天 + 1 套备用（湿热，可酒店洗或手洗速干）

### 4.4 着装礼节

- 进寺庙（若偶尔路过）：肩膀、膝盖需遮盖。本行程以酒店为主，一般用不上正装。

## 7. 安全与健康

1. **红旗绝对不下海**；泳池由大人轮流盯，玩滑道听救生员。  
2. 防晒每 2 小时补涂；热带晒伤次日会很难受。  
3. 过马路靠左，抓牢孩子。  
4. 贵重物品放保险箱；沙滩勿无人看管手机。  
5. 买旅游保险；护照拍照存云盘。  
6. 急诊先问酒店前台；出发前存中国驻泰领事保护相关电话。

## 8. 防坑预判（比较扯淡的事 + 应对）

> 心态：多数不是「针对你」，是旅游区老套路。你有预案就不会被气到，更不会掏冤枉钱。  
> 你们几乎泡酒店，能避开大半坑；下面按「仍可能遇上」排序。

### 8.1 入境与证件类

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 免签≠随便进 | 移民官查返程票、酒店单、资金，材料不齐可能劝返 | 机票/酒店/TDAC/卡+少量现金备好，回答「旅游、住 Katathani、X 日回」 |
| TDAC 收费代办 | 假网站收你几十上百元「代填」 | 只上官网 https://tdac.immigration.go.th ，免费 |
| 「帮忙通关」黄牛 | 机场有人搭讪代办、换汇、打车 | 微笑拒绝，跟着官方指示牌走 |
| 护照有效期/空白页 | 临场才发现不够 | 出发前再看一眼护照 |

### 8.2 交通与司机类

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 机场出租车绕路 / 一口价虚高 | 不打表、故意绕 | **已订酒店 Van 就无视拉客**；没预订再用官方出租车柜台或 Grab |
| 嘟嘟车「固定价」 | 短途喊出旅游价 | 先问价再上车；不爽就改 Grab |
| Grab 司机取消 / 加价 | App 显示一个价，来了要加收行李费 | 开车前在 App 确认总价；有争议取消重叫，或回酒店让前台叫车 |
| 「摩托载客超便宜」 | 雨季路滑，无保险 | **带娃直接拒绝** |

### 8.3 消费与推销类（卡塔周边也可能碰到）

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 海滩/街上拉客「特价海鲜」 | 菜单没标价或事后天价 | 先看**明码价目表**再坐；不爱就说 *no thank you* 走开 |
| 旅游台硬推一日游/SPA 套餐 | 「今天最后名额」「特别优惠」 | 你们酒店度假为主，**默认不订**；真想要先比价、要书面确认含什么 |
| 「免费」「帮忙」带去买宝石/成衣/纪念品店 | 绕一圈逼购物拿回扣 | 不跟陌生人走；不进「朋友的店」 |
| 按摩标价与结账不符 | 低价引流，加项翻倍 | 动手前确认项目与总价；不需要的加项明确拒绝 |
| 换汇「汇率超好」 | 街头黄牛短斤少两、假钞 | **银行/正规兑换点/ATM**；不街头换 |
| ATM 手续费 | 每笔上百泰铢很常见 | 少次多取；优先刷卡 |
| 伴手礼「名牌超低价」 | 假货 | 要正品去商场；不贪便宜 |

### 8.4 海滩与活动类（雨季特别烦）

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 红旗还是有人下水 | 看着别人游就心痒 | **别人作死别跟**；泳池完全够玩 |
| 躺椅/伞收费扯皮 | 有的免费有的收费，说法不一 | 问清价格再坐；不坐就沙滩散步 |
| 摩托艇/水上项目「撞坏要赔」 | 经典坑（巴东更多） | 本行程不玩就彻底避开；若玩务必选正规点、拍照验船、不签空白文件 |
| 「跟我拍猴子/蛇/鸟」要钱 | 拍完狮子大开口 | 不碰、不拍、不给；孩子想看动物去正规场馆（你们这趟可不去） |

### 8.5 酒店与生活类

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 迷你吧/电话/SPA 静默消费 | 退房账单冒出一堆 | 入住问清哪些收费；冰箱里的别乱拿；退房前要账单核对 |
| 「含早」认知偏差 | 儿童早餐另计、某餐厅不含 | 入住确认儿童早餐政策与时间 |
| 房间与图片差 / 加床 | 家庭房理解不一致 | 下单截图留底；不行就礼貌要求换房或加床 |
| 突然大雨计划全废 | 下午雷阵雨 | 本来就酒店度假，当午睡信号；备雨衣 |
| 网络/插座/热水偶发问题 | 度假区常见小毛病 | 找客房部，一般很快处理 |
| 时间观念松 | 餐位、接送偶尔迟到 | 接送机留缓冲；非关键事项别较真 |

### 8.6 人身与规矩类（少见但要知道）

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 对王室不敬很严重 | 踩纸币上的头像、乱评王室 | 纸币别乱折踩；公开场合不拿王室开玩笑 |
| 寺庙着装被拦 | 穿太露不让进 | 本行程几乎不去庙；若去遮肩遮膝 |
| 禁烟海滩/部分公共区 | 可能罚款 | 看标识；不在沙滩抽烟 |
| 药品携带 | 部分感冒药成分受限 | 常用药适量原包装；不确定的别带奇葩托运药 |
| 巴东夜生活乱 | 拉客、酒托、冲突 | **带孩子别去当景点**；晚上回酒店 |

### 8.7 亲子特别容易踩的

| 扯淡点 | 会发生什么 | 应对 |
|--------|------------|------|
| 孩子晒伤中暑 | 玩疯忘记补防晒 | 上午玩水，中午强制休息；帽子+补涂 |
| 泳池无人看管瞬间 | 大人拍照/刷手机 | 两人轮流「值班」，眼睛不离孩子 |
| 生冷海鲜肚子出问题 | 度假拉稀很崩 | 孩子少碰生腌；不干净的摊路过 |
| 语言不通点错辣 | 孩子咬一口狂喝水 | 点餐说 **mai pet**；先大人尝 |

### 8.8 一句话总策略

1. **不跟陌生人走，不签看不懂的单，不明码价不消费。**  
2. **交通靠酒店接送 + Grab，不街边随意拦摩托。**  
3. **推销默认拒绝，需要再主动找前台。**  
4. **红旗、暴雨、肚子、晒伤——这四样比「没逛到景点」严重得多。**  
5. 被缠上就微笑重复：***No thank you*** / ***mai ao***（不要），带孩子直接走开。

## 9. 现金与支付

### 9.1 带什么币种

| 币种 | 建议 |
|------|------|
| **泰铢 THB** | **主货币，现金只换这个** |
| 人民币 CNY | 岛上兑换点少且汇率通常差，不作为主力 |
| 美元 USD | 不必特意带；部分兑换点收，但不如直接持有泰铢方便 |

汇率粗算（会浮动）：**约 1 元人民币 ≈ 4.5–5 泰铢**（出行前再查一眼）。

### 9.2 带多少现金（一家四口 · 5天4晚）

前提：机票、酒店已付；大额尽量刷卡 / Grab。

| 档位 | 泰铢现金（全家合计） | 约合人民币 | 适用 |
|------|----------------------|------------|------|
| 够用 | **15,000–20,000 ฿** | 约 3,000–4,500 元 | 酒店为主、餐饮多刷卡（本行程适用） |
| 更稳 | **20,000–25,000 ฿** | 约 4,000–5,500 元 | 含周边吃饭、小费、伴手礼、应急 |
| 不建议 | 全行程只靠现金，或现金过少（少于 5,000 ฿） | — | 太重或不抗风险 |

**推荐默认：随身现金约 20,000–25,000 泰铢（约 4,000–5,500 元）**，其余靠卡。

现金主要用来：
- 便利店、小吃、水果摊、小面额消费
- 小费（行李员、打扫等，随意 20–100 ฿）
- Grab/网络不好时的出租车备用
- 市场砍价、部分本地小店只收现金
- 入境抽查时展示资金实力（见下）

### 9.3 入境资金说明（与 §1.3.1 对照）

- 使馆口径：个人约 ≥**10,000 ฿**，**家庭约 ≥20,000 ฿** 现金或等值外币；并建议备银行卡等辅助证明。  
- 你们按家庭准备即可；现金计划 **20,000–25,000 ฿** 起，想更稳可提到 **30,000–40,000 ฿**。  
- **实物现金最硬**；卡和手机余额是辅助，过关时别只靠截图。  
- 详细步骤与话术见 **§1.3.1**。

### 9.4 刷卡、支付宝与换汇

#### 支付宝方便吗？

**结论：能用，比以前方便很多，但不能当唯一支付方式。**

| 场景（结合你们行程） | 体验 | 说明 |
|----------------------|------|------|
| 7-Eleven 等便利店 | 很好 | 扫码较稳 |
| 商场 / 连锁餐饮 | 较好 | 常见 Alipay / Alipay+ 标识 |
| 卡塔坦尼酒店账单、餐厅 | 看店家 | **以酒店实际受理为准**；大额先问，不行就刷 Visa/Mastercard |
| 卡塔周边小餐馆 / 摊位 | 一般 | 有的只有泰国 PromptPay 码，国内支付宝不一定都能付 |
| Grab 打车 | 别只靠它 | 更稳：绑国际信用卡 |
| 小费、街头小额 | 不行 | 继续用泰铢现金 |

**怎么用**

1. 出发前确认支付宝已实名，余额或绑定卡可支付。  
2. 到店看有无 **支付宝 / Alipay+** 标识，有就「扫一扫」。  
3. 若是泰国本地码：能付就付，提示不支持就改刷卡/现金。  
4. 付款前看清泰铢金额和汇率提示；图的是方便，汇率未必最优。

**推荐支付组合**

| 方式 | 作用 |
|------|------|
| **泰铢现金** | 保底：小费、小店、应急（仍建议 2–2.5 万 ฿） |
| **Visa / Mastercard** | 酒店大额、餐厅备用 |
| **支付宝** | 便利店、能扫的店 |
| Grab 绑卡 | 偶发出门打车 |

> 一句话：**支付宝 = 加分项；现金 + 国际卡 = 底盘。**

#### 刷卡与换汇

| 方式 | 说明 |
|------|------|
| 信用卡 / 借记卡 | Visa、Mastercard 在酒店、餐厅、商场通用；出发前开通境外交易 |
| Grab | 尽量绑国际信用卡；或到泰后用现金充值钱包 |
| 在哪换泰铢 | **优先上海银行/正规兑换**（汇率通常更好）；或浦东出境后免税区/普吉机场（方便但汇率略差） |
| 当地 ATM | 可取现应急，有手续费（常见单次一百多泰铢起）+ 可能有银行跨境费；**少次多取** |
| 散钱 | 换/留一些 **20、50、100 ฿** 小票，方便买水和小费 |

### 9.5 小费指南（普吉 / 泰国）

泰国**不强制小费**，没有美式那种「不给就失礼」。给了是感谢好服务；不给一般也不会被追着要。酒店账单若已含 **Service Charge（服务费，常见 10%）**，就不必再按比例加一遍。

#### 什么情况给、给多少（泰铢）

| 场景 | 要不要给 | 参考金额（全家或单次） | 说明 |
|------|----------|------------------------|------|
| 酒店行李员帮忙推行李 | 建议给 | **20–50 ฿/件**，或一共 **100–200 ฿** | 4 人行李多，到店/离店各给一次即可 |
| 客房打扫 | 可选 | **20–50 ฿/天** 放床头或桌上 | 连续住可每天放，或退房前一次性给 |
| 酒店餐厅 | 看账单 | 已含服务费 → **零找补凑整**即可；未含 → 满意可留 **50–100 ฿** 或约 5–10% | 不必硬给 10% |
| 外面普通餐厅 / 海鲜店 | 可选 | 账单凑整，或 **50–100 ฿** | 路边摊、小吃、7-Eleven **不用给** |
| 酒吧 / 咖啡 | 可选 | 找零凑整 | — |
| Grab / 出租车 | 通常不给 | 可把车费 **凑成整数**（如 183→200） | 司机很少强要小费 |
| SPA / 按摩 | 建议给 | **50–100 ฿/人**；双人约 **100–200 ฿** | 若价目已含服务费则少给或凑整 |
| 一日游导游 + 司机 | 服务好再给 | 导游 **200–400 ฿/天（全家）**；司机 **100–200 ฿** | 私人包车可略高；团游看表现 |
| 私人司机接送机 | 可选 | **50–100 ฿** | 已付车费后的感谢，非必须 |
| Kids Club / 泳池救生员 | 一般不给 | — | 除非有特别额外帮忙 |

#### 怎么给更自然

- 用泰铢现金，**小面额**（20/50/100）最方便。
- 当面微笑递上即可，不必说很多；会一句 *khop khun*（谢谢）更好。
- 不要给得太张扬，也不要用硬币堆一大把（硬币面值小，适合凑整）。
- **没服务、态度差：可以不给。**

#### 你们这趟的小费预算（粗估）

按「接送各 1 次 + 住 4 晚打扫 + 偶尔餐厅凑整 + 可能 1 次按摩/半天导游」：

| 档位 | 全家合计 | 说明 |
|------|----------|------|
| 偏省 | **500–800 ฿** | 只给行李员 + 少量凑整 |
| 常规 | **1,000–1,500 ฿** | 含客房打扫、1–2 次餐饮/按摩 |
| 偏宽 | **2,000–2,500 ฿** | 再加导游/司机小费 |

> 现金总预算里已含小费；不必再单独多换一大笔，从那 **2–2.5 万泰铢** 里留约 **1,000–1,500 ฿** 作小费备用即可。

### 9.6 携带与保管

- 现金分两处：大人各持一半；大额放酒店保险箱，身上留当天零花（约 1,000–2,000 ฿/天全家）。
- 不要在街头兑换「超好汇率」私人换汇。
