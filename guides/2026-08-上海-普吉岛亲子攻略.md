## 3. 住：卡塔坦尼用法

### 3.1 为什么适合你们

- 位置：小卡塔（Kata Noi），比大卡塔/巴东安静，适合亲子。
- **Aqua Jungle 水上乐园**：滑道、漂流河、戏水区（约 09:00–17:30；滑道常分场次）。
- 多个泳池 + 儿童池；救生衣可问前台/乐园。
- **Chang Noi Kids Club**（约 4–12 岁）：手工、小厨、电影等，两大孩子年龄都合适。
- 餐厅有儿童餐；可问加床/家庭房政策。

### 3.2 入住注意

- [ ] 确认房型：家庭房 / 连通房 / 加床（两人孩子分床更易睡）
- [ ] 抵达后问清：水上乐园位置与场次、Kids Club 是否需预约、儿童早餐是否收费
- [ ] 8/11 晚到：已告知酒店 ETA（预计 15:30–16:30）
- [ ] 8/15 早走：前一晚收拾；问清行李寄存；一般不依赖 late check-out
- [ ] 房间尽量海景（雨天也能在阳台看海）

### 3.3 雨季下海规则

- 8 月西海岸（卡塔/卡隆/巴东）常挂 **红旗**。
- **红旗 = 禁止下海**（包括「只到脚踝」），有离岸流风险。
- 游泳主场 = **酒店泳池 + 水上乐园**。

## 4. 衣：行李清单

### 4.1 天气预期

- 白天约 29–31℃，夜间约 25℃，湿度高。
- 雨多在 **午后短时暴雨**，很少下一整天。
- 策略：**上午户外/玩水，下午酒店或室内**。

### 4.2 每人必带

- [ ] 速干短袖 / 短裤 / 裙子 3–4 套（少带牛仔裤）
- [ ] 泳衣 2 套 + 罩衫
- [ ] 薄雨衣或折叠伞
- [ ] 防滑凉鞋 + 可走路的鞋
- [ ] 帽子、墨镜、高倍防晒霜
- [ ] 薄外套（机舱 + 进寺庙遮肩）
- [ ] 充电宝、转换插头（泰国双圆孔，220V）
- [ ] 防水手机袋

### 4.3 带娃加成

- [ ] 儿童防晒霜、驱蚊液
- [ ] 退烧药、止泻药、创可贴、常用感冒药
- [ ] 泳镜、儿童救生辅助（若孩子不熟水性可自备，酒店也可能有）
- [ ] 少量孩子爱吃的零食（飞机 + 第一天）
- [ ] 换洗衣物按天 + 1 套备用（湿热，可酒店洗或手洗速干）

### 4.4 着装礼节

- 进寺庙 / 大佛：肩膀、膝盖需遮盖。

## 5. 食：吃什么

### 5.1 必尝（大人）

- 冬阴功、青木瓜沙拉、打抛猪肉/海鲜饭、咖喱蟹、烤海鲜
- 芒果糯米饭、椰子冰淇淋、泰奶

### 5.2 孩子友好

| 类型 | 例子 |
|------|------|
| 稳妥 | 炒河粉、炸鸡、意面、白米饭 + 少辣打抛、甜口咖喱饭 |
| 甜品 | 芒果糯米饭、椰子冰淇淋 |
| 便利店 | 7-Eleven：面包、酸奶、水果、水、冰淇淋 |

点餐口令：

- **mai pet** = 不辣  
- **pet nit noi** = 微辣  

### 5.3 就餐策略

- 雷雨天：优先酒店餐厅。
- 想出门：卡塔主街 / 卡隆，用 Grab。
- 避开海滩第一排强拉客海鲜（先看菜单价）。
- 少喝不明来源冰块/生水；瓶装水随时买。

## 7. 安全与健康

1. **红旗绝对不下海**；泳池由大人轮流盯，玩滑道听救生员。  
2. 防晒每 2 小时补涂；热带晒伤次日会很难受。  
3. 过马路靠左，抓牢孩子。  
4. 贵重物品放保险箱；沙滩勿无人看管手机。  
5. 买旅游保险；护照拍照存云盘。  
6. 急诊先问酒店前台；出发前存中国驻泰领事保护相关电话。
